# -COVID-19-Analysis-Dashboard-Power-BI-
Interactive Power BI dashboard analyzing COVID-19 cases, deaths, recoveries, and vaccination trends with dynamic visualizations, KPIs, and geographic insights for data-driven decision-making.

📌 Project Overview

This Power BI project provides an interactive dashboard to analyze the global impact of COVID-19. It visualizes confirmed cases, deaths, recoveries, active cases, and vaccination progress across countries and regions. The dashboard helps users identify trends, compare countries, and monitor the spread of the pandemic over time.

🎯 Objectives
Monitor COVID-19 cases worldwide.
Analyze trends in confirmed cases, recoveries, and deaths.
Compare COVID-19 statistics across countries and regions.
Track vaccination progress.
Provide interactive insights for data-driven decision-making.
